| 13:19:46 | общий ключ 4103 снова → `+4103`; 13:20:06 загрузка → `-4103` |
Таблица сумки при этом не меняется: игра на каждой загрузке фантома восстанавливает фантомную сумку из снимка,
сделанного при входе (вместе с `bag clear 0x014D0030 flag 1`, callers `0x14e6676 <- 0x18d866a <- 0x18da774`, пачками
на каждой загрузке). При выходе домой — переключение на свою таблицу `0x100806f730` (`INVENTORY TABLES CHANGED`),
где ключевых из поездки нет.
**Решение пользователя:** раз это делает игра — мод после КАЖДОЙ загрузки в мире хоста (и после возвращения домой)
тихо проверяет ключевые/уникальные предметы, полученные в этой поездке (журнал знает коды), и дописывает недостающие.
Никаких удалений модом. Лучше — найти снимок фантомной сумки (`0x18d866a`/`0x18da774` → `0x014D0030`) и дописывать
подобранное в него при подборе; тогда «после каждой загрузки» станет проверкой, а не починкой.
