## Подтверждено

- ПК: RTX 5070, драйвер Windows `32.0.16.2101`, дата 2026-10-19.
- Настройки на момент сбоя: `upscaler=dlss`, `frame_gen=dlss`, множитель 2,
  preset 0, вывод 2560x1440.
- Два отдельных эпизода: nvlddmkm event 153 в 00:21:27/30 и 00:28:49/52 МСК.
  Windows Error Reporting зарегистрировал оба как LiveKernelEvent 141,
  bucket `LKD_0x141_Tdr:6_IMAGE_nvlddmkm.sys_Blackwell`.
- WER ссылается на WATCHDOG-20261030-0021.dmp и WATCHDOG-20261030-0028.dmp.
  Дампы в этой сессии не анализировались; содержимое не подтверждено.
- Последний мод-лог хоста обрывается в 00:28:49.127, рядом с событием драйвера.
  Отдельных событий Application Error 1000/1002 в собранном интервале не найдено.
- Это подтверждение GPU timeout/TDR, а не доказательство конкретного дефекта DLSS FG.
  Нельзя по этим логам исключить графический код порта, взаимодействие подсистем
  или драйвер; нельзя объявлять мод полностью непричастным.
- `last_run.log` содержит только подготовку/загрузку порта (468 байт), полноценной

Бэкап ini: `D:\Games\Bloodborne\bbport-coop\bbport.ini.bak-gpu-control-20261030-003430`.
Сейвы не откатывались. Реестр/TdrDelay и драйвер не менялись.

Следующая проверка: тот же ПК-хост, ноут-гость, тот же маршрут/действия минимум 10–15 минут
без Frame Generation. Отсутствие TDR в одном прогоне усиливает гипотезу о FG, но само
по себе ещё не доказывает причину. Если повторится — проверить DLSS upscaler отдельно
и получить доступный GPU/runtime crash dump; менять параметры по одному.
