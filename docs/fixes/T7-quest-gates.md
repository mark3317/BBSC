# T7 — ранняя лента, дверь с собакой и аналогичные личные события

## Подтверждённые причины

Данные CUSA03173 1.09, исходные файлы игры не изменялись.

1. **Белая лента раньше времени.** `m24_01` / 12410702 управляет телом сестры:
   объект и сокровище 2410851 выключены, пока личный флаг завершения 1273 не установлен;
   затем включаются. У события есть проверка типа игрока 0, а в прежнем списке
   разрешённых гостю оно отсутствовало. Лог T6 прямо показывает
   `event 12410702 waits on the host's player type - not for the guest`.
   Гость создаёт собственные предметы, но не выполняет скрывающую их часть квеста.
2. **Дверь после собаки.** 12410748 ждёт игрока в регионе 2412280 и смерти собаки
   2410143, затем через 30 кадров включает 72410393. `t241316` ждёт этот флаг,
   чтобы произнести 2600210/2600260 и установить личный флаг знакомства 72410382.
   Событие также закрыто типом 0 и отсутствовало в разрешённых. T6 логирует отказ.
   До знакомства событие стука 12410750 ждёт 72410382, поэтому починка стука сама
   по себе не открывала эту дверь.
3. **Ретро выдавало красную ленту в начале игры.** ItemLot 12702411 / 4904 использует
   72410410 как блокировку дропа. 12410713 сначала ставит его в 1, а после нужных
   условий квеста и владения красной лентой снимает. Это не доказательство получения.
   В T6 в 23:00:15 у хоста и 23:00:34 у гостя `K2-retro` выдаёт 4904 по этому флагу.

## Исправление

- `tools/gamedata/quest_event_rules.py` сканирует все EMEVD и ItemLotParam,
  генерирует `bbsc_quest_event_rules.h`; `--check` проверяет соответствие данным.
- Найдены 15 дополнительных событий, чьи эффекты ограничены известными личными
  NPC-флагами и настройками сети/сохранения. В их числе разговор после собаки,
  проверки предметов для NPC, реакции на урон и вход в области разговора в разных картах.
  Запуски дочерних событий, награды, изменения мира и параметризованные записи не
  проходят это автоматическое правило.
- Отдельно просмотрено и разрешено 12410702: его эффекты касаются оконных прокси
  сестры и её квестового тела/предмета. Другие события с изменениями объектов/персонажей
  автоматически не разрешаются. Например, сложный 13600950 оставлен без изменений.
- Эти 16 событий выполняются гостем локально, без штатного NetworkSync. Их собственные
  записи флагов проходят охрану NPC и попадают в журнал поездки. 72410410 добавлен
  к личным флагам. Три уже исправленных обработчика стука остаются локальными.
- Найдены 40 флагов ItemLot, которые явно меняют игровые события. Ретро не считает
  их значение доказательством получения: для них нужны журнал лотов либо подбора.
  Обычные флаги получения (включая 52410900/50002200 для белой ленты) продолжают
  восстанавливать предметы. Сверка реально полученного в поездке не отключается.
- Уже выданные предыдущей версией предметы не удаляются.

## Проверка

Сканер и сборка проверяются перед деплоем. Игровое подтверждение пока отсутствует.
Изменения только в моде; порт и VPS не требуют пересборки/деплоя.

Следующий тест на чистом снимке `start-clinic-teststart` (поздние журналы нужно
отложить с резервной копией, иначе они возвращают уже полученные ленты):

1. ПК-хост и ноут-гость, персонаж `testStart`: в начале белой ленты под окном нет;
   красная лента не выдается ретро при загрузке/входе.
2. Убить собаку у двери старушки, подойти каждым игроком: вступительная реплика,
   затем личный разговор/стук работают. Повторить с убийцей-гостем.
3. Обычные окна и награды за свой разговор не изменились.
4. Пройти цепочку сестры до 1273: белая лента появляется для соответствующего
   игрока и сохраняется после загрузки/возвращения домой.
5. Повторить загрузку: ретро не выдаёт ленты лишь по служебным флагам.

Ограничения: изменения состояния оконных прокси/тела требуют проверки на влияние
на хоста; локализация события не является доказательством отсутствия всех других
сетевых путей объектов. Полная цепочка квеста в игре ещё не проверена.
