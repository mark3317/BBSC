## Изменения

- Native context hook теперь может подготовить чашу по свежему connect-first
  claim при первичном призыве. Это работает и когда R13/driver map не распознаны:
  источник намерения — принятый claim, источник генерации — согласованные свежие
  follow/Mount/полный снимок. При нехватке данных выдуманный контекст не применяется.
- Join teleport проверяет фактический mounted context/карту. Если подземелье ещё
  не загружено, передаёт управление scoped follow без переноса координат. Follow
  может восстановить m29 и при временной невалидной runtime карте. Лишний второй
  join reload ради освещения обычных карт для уже смонтированной чаши не запускается.
- Новый byte-checked entry hook `013CDE30`, `55 48 89 E5 41 57`, перехватывает
  не принадлежащий BBSC запрос живого уже подключённого cooperator в m29 до записи
  global+08/teardown. Запрос подтверждается без загрузки, загрузку делает follow
  после свежего полного контекста хоста. Синхронный RequestBbscSessionWarp отмечает
  владельца запроса; его hook пропускает. Сам StageTransition endpoint подтверждён
  локальным disassembly: первая запись global+08 в `013CDE45`.
- Первичный summon, host, invader, смерть, свой мир, обычные карты не фильтруются.
  Диагностический trace не занимает тот же entry, даже с Research ON.
- T20 поиск/таймер колокола, постоянные алтари и существующие журналы не меняются.
