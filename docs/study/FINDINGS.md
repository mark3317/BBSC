## Связки (одна причина — несколько симптомов)
1. **Диск для журналов гостя:** LA-1 → GI-2 → WS-2 (+WS-3). Если слот не известен, весь механизм «переживания краша» (own world, pending progress,
   guest-items) работает только в памяти.
2. **Доставка флагов хоста:** SN-02 (глобальная рассылка, лимиты очередей) + SN-18/WS-7 (тихие потери) → WS-6/SN-08 (загрузка на своих флагах) →
   исходный баг «босс умер сам, эхо и чаша гостю».
3. **Рост диска:** GI-3 + LA-2.
4. **Дубли данных между репо:** HI-1 + PE-1.
