# BBSC-GL — Bloodborne Seamless Co-op Game Launcher

[English](README.md) · **Русский** · [Скачать BBGL](https://github.com/mark3317/bbgl/releases/latest)

BBSC-GL — форк [Bloodborne Seamless Co-op (BBSC)](https://github.com/CLSAMG22/BBSC) от mark3317 для **[Bloodborne Game Launcher (BBGL)](https://github.com/mark3317/bbgl)**. Для игры скачайте BBGL: согласованные версии мода и сервера уже включены.

## Идея

Оригинальный BBSC уже предоставляет бесшовную сессию, предметы гостей, общий прогресс, масштабирование врагов и до пяти охотников. Эти возможности созданы авторами оригинала. Наш форк сосредоточен на полном совместном прохождении в Windows-порте: гость взаимодействует с миром, получает свои квестовые награды и возвращается в собственный мир после игры с друзьями.

Цель — одно подключение на игровую сессию, включая смерти, переходы и чаши. Это направление разработки, а не гарантия всех сценариев. Миграции хоста нет.

## Архитектурные отличия

- **Единая поставка.** Оригинал предлагает отдельные Play / Server / Nucleus / BBport-пакеты. В BBGL клиент и сервер собираются из закреплённого подмодуля и поставляются вместе с лаунчером.
- **Основная платформа — Windows-порт.** BBport DLL и загрузчик — основной путь интеграции; код эмулятора остаётся основой игровой логики мода.
- **Свой мир гостя.** Поверх синхронизации оригинала развиты снимки собственного мира, журналы предметов и ожидающего прогресса по слотам сохранений, восстановление, личные награды NPC и собственный Сон охотника. Общий прогресс добавляет допустимые достижения после возврата; флаги мира чаш исключены из слияния.
- **Восстановление сессии.** Добавлены исправления смерти, загрузок, камеры наблюдателя, повторного призыва и следования в чаши. Последнее исправление повторяет выдачу ключевых предметов после загрузки гостя.
- **Разделение файлов.** Бинарные файлы остаются в установке BBGL, изменяемые данные — в `%LOCALAPPDATA%\bbgl`. `BBSC_DATA_DIR` перенаправляет данные мода; без неё работает прежняя самостоятельная раскладка.
- **Сеть сохраняет основу BBSC.** Используются shadNet, штатный сетевой слой игры и relay игрового сервера с исправлениями форка. Собственные сообщения дополняют штатный обмен, а не заменяют весь боевой протокол.

[Обзор архитектуры](docs/study/ARCHITECTURE-OVERVIEW.md) · [Синхронизация мира](docs/study/bbsc-world-sync.md).

Внутренние имена `bbsc.dll`, `bbsc-launch.exe`, переменные `BBSC_*` и идентификаторы протокола сохранены ради совместимости. Название форка и репозитория — **BBSC-GL / bbsc-gl**.

## Готовность

Экспериментальная версия. Базовое прохождение чаш и два исправления входа T21 подтверждены игроком. Задержка боя в чашах, редкие сценарии смерти и обрыва связи, разные подземелья и три игрока требуют контроля. Исправления T24 камеры и T25 повторной выдачи ключей прошли проверки кода/сборки; это не означает завершённого игрового тестирования. [План и результаты](docs/BACKLOG.md).
